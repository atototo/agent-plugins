# OpenCode delivery

Use available browser tools, a connected MCP, or an installed browser CLI through
the permitted shell. Web search and webfetch do not render a local HTML document.
Deliver the actual saved file path as a clickable file reference where supported,
or a clear absolute path otherwise. Do not infer browser automation from the fact
that OpenCode's interface itself runs in a browser. Do not emit native Visualize or
Claude Artifacts syntax unless the current host explicitly supports that surface.
